# @dendrop/desktop

The Windows 11 and Linux app (Electron), wrapping the web client in `packages/web`.

Not built yet. Planned in Phase 2 of [the roadmap](../../docs/ROADMAP.md): installer, tray,
start with the PC, global keybinds (push-to-talk, mute, deafen), pop-out chats, auto-update,
and sign-in through the system browser for TinyAuth.
